fix: services hero now actually shows its background + assistant flow rework + ROZE imagery

Services hero (the biggest user-visible bug):
- Section was missing `isolate`, so every -z-10 layer (the photo, the
  vignette, the bottom fade, the blue glow) sat *behind* the section's
  own `bg-neutral-950`. Result: the hero rendered as flat black and the
  background image was invisible no matter how thin we made the overlay.
- Added `isolate` to create a proper stacking context for the section,
  matching the homepage hero's stack.
- Dimmed the radial vignette (65/35/15 -> 85/65/35) so the headline +
  body copy stay readable on top of the cityscape + floating UI cards.

Sales assistant:
- Rewrote the system prompt as a 4-phase state machine (Route -> Discover
  -> Recommend with choice -> Book) with explicit first-turn routing for
  the 6 quick-reply openers + free-form pain mentions + greetings.
- Hard rule against re-asking what the visitor just said.
- Recommendation replies now always emit ALL three links (bundle card,
  matching single service, Calendly) with the same incrementally-built
  discovery note, so the visitor picks the smallest fit they want.
- Added a skip-to-book shortcut for "book a call" / "I just want to talk".
- Tightened brevity rules + added worked examples so default replies stay
  under 40 words and only expand when explicitly asked for detail.

ROZE imagery:

  orchid.jpg, sofia.jpg, rose-valley.jpg, nesebar.jpg (products) +
  editorial-wedding.jpg, editorial-cashmere.jpg, editorial-atelier.jpg
  (Editorial section).
- lib/roze-data.ts: wired image paths onto the matching products; rest
  still fall back to the gradient swatches.
- app/projects/boutique-fashion-brand/page.tsx: CartRecovery thumbs +
  Editorial cards now use next/image with the gradients sitting behind
  as graceful fallbacks.

Homepage polish:
- Featured "Curated." card badge: "Flagship demo + star icon" -> "Live
  demo + dot" to match the other cards' badge style and stop wrapping
  awkwardly on narrow viewports.

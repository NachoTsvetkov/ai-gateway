# Shopify Conversion Leak Fix Kit

**Version 1.0** · For Shopify merchants running paid traffic

You paid for this kit because traffic is landing but checkout isn't converting. This package gives you a **15-minute audit**, a **prioritized fix order**, and **copy-paste blocks** so you can ship improvements this week — without an agency.

---

## How to use this kit (30 minutes total)

1. **Baseline (5 min)** — Open Shopify Analytics → Online store conversion over time. Note last 7 days: sessions, add-to-cart rate, checkout reached, purchase rate.
2. **Audit (15 min)** — Open `01-15-minute-audit.md` on your phone. Walk your top product page → cart → checkout. Score each leak 0–2.
3. **Fix (pick 1–2 leaks today)** — Use `02-five-leaks-playbook.md` for step-by-step Shopify fixes.
4. **Copy (10 min)** — Paste blocks from `03-copy-paste-blocks.md` under your Add to Cart button and cart drawer.
5. **Track weekly** — Log numbers in `04-conversion-tracker.csv`. Compare week-over-week checkout completion.

## Priority order (if you only have one afternoon)

Fix in this order — highest ROI first for paid-traffic stores:

| Priority | Leak | Why first |
|----------|------|-----------|
| 1 | Surprise shipping at checkout | Kills intent at the last step |
| 2 | Mobile checkout friction | Most Meta traffic is mobile |
| 3 | Weak trust on the buy button | Cold traffic needs proof near CTA |
| 4 | Slow mobile PDP | Hurts every ad click |
| 5 | Ad ↔ landing message mismatch | Fix when running dedicated LPs |

# Copy-Paste Fix Blocks

Replace `[BRACKETS]` with your store details. Paste into theme sections: **Product information**, **Custom liquid**, or cart drawer snippet.

---

## Block 1: Shipping + trust under Add to Cart (PDP)

```
✓ Free shipping on orders over $[THRESHOLD]
✓ [XX]-day hassle-free returns
✓ Secure checkout · Shop Pay & Apple Pay accepted
Estimated delivery: [X–Y] business days to [COUNTRY]
```

---

## Block 2: Free-shipping progress (cart drawer)

```
You're $[AMOUNT_REMAINING] away from free shipping!
🚚 Free shipping unlocks at $[THRESHOLD]
```

*Tip: Use a free-shipping bar app or theme section that calculates remaining amount dynamically.*

## Block 3: Review social proof (one line)

```
★★★★★ "[Specific outcome quote]" — [First name], verified buyer
```

## Block 4: Low-stock (only if true)

```
Only [N] left in stock — order soon for [DAY] delivery
```
